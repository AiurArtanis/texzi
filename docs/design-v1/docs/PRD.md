# texzi 产品需求文档

版本：1.0 设计交接稿　日期：2026-11-15　平台：Windows 10 x64 / Windows 11 x64

## 0. 文档地位与实施约定

本文定义首版产品行为，与 [UI_SPEC.md](UI_SPEC.md)、[COMMANDS.md](COMMANDS.md)、[SETTINGS.md](SETTINGS.md)、[TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)、[PERFORMANCE_PLAN.md](PERFORMANCE_PLAN.md)、[HANDOFF.md](HANDOFF.md)、[ACCEPTANCE.md](ACCEPTANCE.md) 共同使用。命令名称、Windows 默认快捷键和快捷键冲突规则以 COMMANDS 为唯一来源；设置字段、枚举、默认值、生效时机与依赖以 SETTINGS 为唯一来源。本文不得被“框架自带相似组件”替代。

### 0.1 已确认要求

- 名称为 **texzi**，用于临时文字、普通文本、Markdown 与代码片段；采用 NSH；首版面向 Windows x64。
- 文本编辑能力与窗口组织参照 VS Code；具体行为在本稿和命令表中逐项定义。对照基线为 VS Code **1.146.0**，commit `69047191fc427f2f92828279aae1d90d8eeda7ab`；没有核实的默认值不得冒充 VS Code 默认。
- Markdown 默认直接编辑排版后的正文，即原生所见即所得；正文右上 `>_` 在当前位置切换源码，再次切换返回排版态。保留原始 Markdown，跨模式使用同一撤销历史。
- 已审阅的三张概念图规定主界面、Markdown 分屏与设置的视觉方向。顶栏没有应用名称或文档标题文字；菜单、搜索入口、Windows 窗口控制位于同一行。
- “Z 模式”已明确为 **Zen 专注模式**。
- 风格为克制的白色与中性灰、灰蓝层级及蓝色强调；编辑字号基准 16 DIP，界面字号基准 14 DIP；默认隐藏 minimap。
- 默认 Markdown 所见即所得、自动保存关闭、恢复上次会话开启。编辑器不判断文本是否敏感。
- 首版不展开完整 IDE、插件市场或扩展生态。
- 用户已接受前轮提出的性能目标；具体数值、测试口径与适用模式统一见 PERFORMANCE_PLAN，尚无本产品原生实测结果。

### 0.2 本稿中的设计建议

单根工作区、每窗最多 8 个编辑组、布局最小尺寸、搜索引擎及预算、大文件阈值、恢复写入周期及新增分项预算均为本方案提出的实施基线，不是用户此前逐项指定的要求。实施团队应按此开展验证；如果证据表明不可达，先提交差距及替代方案，不能静默删减已确认能力或降低已接受的性能目标。

所有时间、内存与文件规模门槛都需要在锁定的原生构建、硬件和系统版本上测量。HTML 原型只证明交互设计，不能作为 NSH、Windows IME、文件恢复或性能已通过的证据。

## 1. 定位、场景与成功标准

texzi 是打开即写、长期保留文字的桌面文本编辑器。首屏将绝大多数面积留给内容，日常流程在文件、标签和编辑区内完成。代码片段享有通用文本编辑和语法高亮，不引入项目构建、调试或语言服务的必要依赖。

| 场景 | 用户起点 | 必须完成的结果 | 首版级别 |
|---|---|---|---|
| 临时记事 | 启动应用，尚未选择文件夹 | 立即输入，关机或崩溃后恢复已持久化内容，之后可另存为 | P0 |
| 日常文字整理 | 打开笔记文件夹 | 文件树定位、多标签切换、搜索替换、保存及外部变化处理 | P0 |
| Markdown 写作 | 双击 `.md` | 直接编辑标题、任务、表格和代码块；需要时原位切源码 | P0 |
| 对照修改 | 同时查看笔记、片段、待办 | 左右/上下分屏，独立滚动，同文档多个视图保持一致 | P0 |
| 批量改片段 | 选择重复单词或多行 | 多光标、矩形选择、正则查找替换；整批操作可一步撤销 | P0 |
| 双显示器工作 | 拖动标签到另一窗口 | 文档不复制为互不相干的副本，不丢选区和未保存状态 | P0 |
| 大文件排查 | 打开几十至数百 MiB 的日志 | 可取消加载、明确降级、仍能定位和查找；不锁死主窗口 | P0 |
| 专注写作 | 已打开文档 | Zen 收起辅助区域，保留安全退出路径，退出恢复布局 | P0 |

成功以可执行验收衡量：不丢已确认写入的内容、编辑行为可预测、中文输入不中断、视图状态不串扰、可解释地处理文件冲突，并达到经验证通过的性能门槛。

## 2. 首版范围与非目标

### 2.1 P0：首版发布阻断项

普通文本编辑、Unicode 选择、基础与多光标编辑、矩形选择、撤销重做、剪贴板、文件内查找替换、文件夹文本搜索；独立文件与单根工作区；标签预览/固定/关闭；递归分屏与多窗口；原生 Markdown 所见即所得及源码切换；原文保真；常用语言高亮；设置与快捷键管理；编码/换行；会话恢复；外部变化冲突；大文件模式；Windows IME、DPI、键盘及辅助功能。

### 2.2 P1：首版后增量，不得拖延 P0

文件夹批量替换与逐文件预览确认、多根工作区、会话命名快照、文档大纲、用户自定义主题导入、可配置 minimap、完整 Markdown 数学排版与 Mermaid 图形渲染、其他 Markdown 方言、任意所见即所得多光标、Git 差异视图与扩展式语言注册界面。

### 2.3 非目标

LSP、补全建议、调试器、终端、运行代码、依赖管理、构建任务、Git 提交工作流、插件商店、账号体系、云同步、协同编辑、AI 写作与敏感内容检测。内部模块化和命令注册是工程边界，不意味着首版向外开放插件 API。

## 3. 核心对象与不变量

| 对象 | 负责什么 | 不应负责什么 |
|---|---|---|
| Document | 文本/原始字节映射、修订号、编码与换行、dirty、文件身份、唯一撤销历史、恢复记录 | 当前窗口的布局 |
| EditorView | 文档引用、模式、光标/选区、滚动锚点、折叠、查找栏状态 | 保存另一份独立正文或撤销历史 |
| EditorGroup | 按顺序排列的标签、活动标签、一个预览位 | 文件所有权 |
| Window | 单根工作区或无工作区、分屏树、焦点、Zen、窗口状态 | 重复创建同一文档内容 |
| Session | 可恢复的文档、视图与窗口关系及最近持久化版本 | 把未保存内容直接写进原文件 |

**必须保持的不变量：** 同一个逻辑文档只有一份权威内容与撤销历史；多个视图可以有不同模式、位置和选区。切换模式、切换标签和移动窗口均不能改变正文、dirty、编码、换行或撤销深度。同一文件身份被多个路径打开时，优先根据系统文件身份去重，路径是回退键；不自行改写文件名大小写或路径内容。

## 4. 启动、工作区与文件树

| ID | 规则 |
|---|---|
| FR-WS-01 | 首次启动打开一个可输入的“未命名-1”纯文本标签；文件树空态显示“打开文件夹”，不强制先建项目。 |
| FR-WS-02 | `session.restoreOnStartup=true` 时加载上次窗口/标签关系；未保存正文是否自动挂载同时受 `session.restoreUnsaved` 控制，关闭后仍可在恢复中心查看已有记录。先呈现可操作窗口，再异步恢复非活动文档。恢复进度不挡住新建临时文本。 |
| FR-WS-03 | 每窗最多一个根目录。打开另一个目录可替换当前根或在新窗口打开，选择入口明确；替换树不自动关闭已有独立文件和 dirty 标签。 |
| FR-WS-04 | 工作区外的文件可作为独立标签打开；面包屑显示其真实路径。没有根目录时仍有完整编辑、保存和文件内搜索能力。 |
| FR-WS-05 | 目录惰性枚举，展开时加载，不递归读取全部文件内容。排序默认目录优先、名称自然排序；文件树刷新不能夺走编辑焦点。 |
| FR-WS-06 | 树单击进入预览标签，双击/显式打开转普通标签。重命名、新建文本/目录、删除、在资源管理器中显示放入上下文菜单。删除优先进入回收站；回收站不可用时说明并要求明确确认永久删除。 |
| FR-WS-07 | 符号链接/联接显示可识别状态；递归搜索避免环路，不默认跟随根目录之外的链接。权限不足、断连和目录不存在以当前节点状态呈现。 |
| FR-WS-08 | 文件拖入内容区打开文件，目录拖入窗口触发打开文件夹流程；多文件按拖入顺序打开。拖入 Markdown 正文时的图片行为见 FR-MD-12，避免与打开文件手势混淆。 |

文件树不是编辑器的唯一入口。菜单、系统打开方式、命令面板、文件拖放均落到同一打开服务。重复打开已存在的文档优先聚焦其当前窗口的现有视图；显式“在侧边打开”才创建额外视图。

## 5. 标签、分屏与多窗口

| ID | 规则 |
|---|---|
| FR-TAB-01 | 标签显示文件名、未保存圆点、固定状态和关闭按钮；同名文件增加最短可区分父目录，悬停显示完整路径。正文类型用克制图标表达，不靠颜色区分。 |
| FR-TAB-02 | 每个组一个预览位，名称斜体。预览只替换未修改的预览标签；一旦输入、固定、双击或移入其他组即转为普通标签。任何 dirty 文档都不得被预览替换丢弃。 |
| FR-TAB-03 | 固定标签排列在本组普通标签之前，拖动保持固定分区；关闭其他/关闭右侧默认排除固定标签，菜单注明这一行为；显式关闭当前固定标签有效。 |
| FR-TAB-04 | 活动标签溢出时自动滚入可见；鼠标横向滚动与标签列表都能访问隐藏标签。不通过缩小字体塞入全部标签。 |
| FR-TAB-05 | 关闭一个视图，若其他视图仍引用该文档，只移除视图。关闭最后一个 dirty 视图才显示“保存 / 不保存 / 取消”。临时文档的保存进入另存为。取消应停止当前批量关闭流程且保留尚未关闭的标签。 |
| FR-TAB-06 | 关闭其他/关闭全部依确定顺序检查 dirty 文档，可用汇总对话框逐项选保存/放弃；不能对重复视图弹重复保存提示。最近关闭仅恢复尚可用的文件和视图位置，不恢复用户明确放弃的正文。 |
| FR-WIN-01 | 分屏为可递归横向/纵向切分的树，可组合左右与上下。建议每窗最多 8 组；最小组尺寸 240×160 DIP。超过上限或最小尺寸时禁用本次分屏并解释，可使用新窗口。该上限是实施建议。 |
| FR-WIN-02 | 分割线可拖动；双击复位当前兄弟组比例为 1:1。关闭最后一个标签移除空组，剩余兄弟组填充；最后一组保留空态或新建临时文本。 |
| FR-WIN-03 | 拖标签到组中心是移动，到四边分屏热区是新建对应组；操作前有落点预览。按住复制修饰键创建同文档新视图，具体键以 COMMANDS 为准。取消拖动不得改变布局。 |
| FR-WIN-04 | 拖出应用窗口创建新窗口；拖入另一个 texzi 窗口移动视图。操作提交采用先确认目标接管、后移除来源，不能先销毁来源；视图模式、选择和滚动位置一并迁移。 |
| FR-WIN-05 | 所有窗口由同一应用文档服务协调文档身份与保存。相同文档在不同窗口编辑实时一致；撤销针对该文档最近一次事务，可撤销另一视图刚完成的修改，并在状态区说明来源。 |
| FR-WIN-06 | 窗口关闭与标签关闭区别明确：只有 `session.restoreOnStartup && session.restoreUnsaved && snapshotFlushSucceeded` 三项同时成立，关闭窗口才可不弹保存提示而保留 dirty 内容供下次恢复；任一开关关闭或快照落盘失败，均逐文档执行保存/放弃/取消流程。显式关闭最后一个 dirty 标签始终提示，不使用这一关窗豁免。关闭一个窗口不关闭其他窗口。 |
| FR-WIN-07 | 多显示器位置在恢复时校正到现有可用工作区；缩放比例变化后光标、点击区域与 IME 候选位置正确。保留 Windows Snap、最大化、还原、系统菜单和标准关闭行为。 |

## 6. 文本编辑规则

本节对普通文本、代码和 Markdown 源码适用。Markdown 所见即所得的适用差异在第 8 节定义，不允许按钮无响应或悄悄忽略命令。

### 6.1 位置、选择与移动

| ID | 规则与边界 |
|---|---|
| FR-TXT-01 | 支持插入、覆盖现有选区、Backspace/Delete、换行、整行删除、行上/下插入、缩进/反缩进、行移动/复制、行首尾/文档首尾/页移动。每个命令的默认键及 when 条件见 COMMANDS。 |
| FR-TXT-02 | 左右移动、Backspace/Delete 不拆开扩展字素簇，包括代理对 emoji、肤色修饰、ZWJ 序列与组合重音。UI 的逻辑行列与底层位置换算保持一致；Tab 展开宽度和实际字符偏移不混用。 |
| FR-TXT-03 | 鼠标单击定位、拖动选择、双击选择词、三击选择逻辑行；Shift 单击延伸锚点。跨软换行选择仍按同一逻辑行处理，选择跨行须包含真实换行而非视觉折行。 |
| FR-TXT-04 | 单词导航/选择使用统一 Unicode 分词策略：拉丁字母、数字、连接标点与组合标记形成词，空白和配置分隔符分界；中文行为须有固定样例，并与全字搜索共用同一边界定义。首版不依赖中文语义分词词典。 |
| FR-TXT-05 | 矩形选择按视觉列建立每行子选区；Tab 显示为配置宽度。未输入前不向短行写入空格；输入发生时才补齐虚拟空间。软换行开启时矩形以当前视觉行工作，切换换行后保留逻辑子选区。 |
| FR-TXT-06 | 多光标可通过添加光标、选择下一个匹配、选择全部匹配、上下添加光标和拆分选区为各行创建。主光标为最后操作的光标，自动滚动只追随主光标。Esc 先回到单一主选区。 |
| FR-TXT-07 | 重复光标去重；重叠或接触的非空选区归并为并集；落入非空选区的空光标移除。按文档顺序计算结果，从后向前提交不重叠编辑。不能因重叠而重复删字、重复粘贴或跳过用户输入。 |
| FR-TXT-08 | 各选区输入/删除/缩进作为同一事务；其中一个光标不能执行某动作时，其余可执行位置正常处理，该位置保留，不产生额外字符。批量变更后各光标锚点按同一事务映射。 |

### 6.2 剪贴板、缩进与代码片段

| ID | 规则与边界 |
|---|---|
| FR-TXT-09 | 普通复制保留选中文字；无选区时复制整逻辑行并带换行。剪切等价于复制后一次删除；剪贴板写入失败则不得删除原内容。复制多选区的纯文本按文档顺序用换行分隔，并附应用内多选元数据。 |
| FR-TXT-10 | 从 texzi 多选复制回同数量光标时一对一粘贴；普通外部纯文本默认完整内容粘到每个光标。可通过“按行分配粘贴”显式把行分配到光标，数量不匹配时解释并取消，不猜测。 |
| FR-TXT-11 | 粘贴保留内容本身，不自动格式化代码。换行转换遵循目标文档规则，混合换行文档按第 10 节处理。大粘贴可后台准备；取消前未提交的内容不得部分进入文档。 |
| FR-TXT-12 | Tab/Shift+Tab 作用于选中逻辑行；无选区按当前位置插入缩进。默认宽度、空格/Tab 与语言例外以 SETTINGS 为准。自动缩进仅复制或调整前导缩进，不启动格式化器。 |
| FR-TXT-13 | 代码范围只包含语法高亮与通用文本命令。第一版至少覆盖 JSON、JS/TS、Python、SQL、PowerShell、Shell、C/C++/C#、HTML/CSS、XML、YAML、TOML、INI、Markdown；未知语言显示纯文本且允许手动选择。不能把高亮失败当文件打不开。 |
| FR-TXT-14 | 括号配对、自动闭合、自动环绕按 SETTINGS 执行；中文引号与输入法预编辑期间不得触发英语配对规则。高亮与括号匹配不应阻塞文字提交。 |

### 6.3 撤销、输入法与编辑状态

| ID | 规则与边界 |
|---|---|
| FR-TXT-15 | 撤销/重做按 Document 维护；多光标编辑、一次粘贴、全部替换、单次表格结构操作都是一个事务。撤销同时恢复对应内容和发起视图的合理选区，其余视图映射到仍有效的位置。 |
| FR-TXT-16 | 连续相邻普通输入在间隔不超过 750 ms、选区不变且没有命令/移动/换行的前提下可合并；此 750 ms 是建议参数。移动、删除方向改变、粘贴、Enter、显式命令、模式切换或 IME 开始/结束应划分边界。模式切换本身不新增撤销项。 |
| FR-TXT-17 | 保存不清空撤销历史。撤销回到保存修订时 dirty 清除，再编辑或重做离开则重新出现。撤销后新编辑清空 redo 分支；只切换视图不清空。 |
| FR-TXT-18 | IME 预编辑文本只在活动输入点显示，候选确认后一次提交；取消组合不改变文档或 dirty。多光标源码输入时，预编辑显示在主光标，确认后的完整结果按同一事务写入所有光标。 |
| FR-TXT-19 | 组合输入期间候选确认/取消/翻页优先于应用快捷键；不得抢占 Enter、Esc、方向键或将拼音拆作普通多次输入。切焦点采用系统组合结束流程；结束结果确定前不得销毁输入视图。 |

## 7. 查找、替换与文件夹搜索

### 7.1 两种明确的查找范围

| 起点 | 默认查找范围 | 行为 |
|---|---|---|

正文查找不是“仅查当前屏幕”。其投影文本由确定的块遍历得到：段落/列表项以换行分隔；表格单元格以制表符分隔、行以换行分隔；代码保留内部换行；任务框不是文字 `x`。原样块按画面显示的字面内容纳入。文字到源码、渲染位置均有映射。查找不能因为图片尚未载入而改变普通文本命中数。

## 8. 原生 Markdown 所见即所得

### 8.1 核心合同

FR-MD-01：`.md` 默认所见即所得，以原生编辑模型呈现正文。它必须可直接输入和修改，不能用只读预览冒充。源码与排版态引用同一个 Document；`>_` 是当前视图的模式开关，其他视图的模式不变。

FR-MD-02：**原始 Markdown 是权威数据。** 打开、阅读、切换模式、移动光标和未修改保存必须保持原始字节（含 BOM、换行、空行及未知语法的所有原文）。直接编辑通过源范围映射局部 patch 完成；不能全篇反序列化再统一序列化。被修改的块可能需要局部规范化，允许范围必须在具体命令中确定，未修改块不可变化。

FR-MD-03：模式切换把当前源码锚点映射为排版位置，反向同理；无法精确对应时落到同一块最近可编辑位置。切换不改变 dirty，不新增撤销项，不清空 redo。源码中删除了对应块时，其他视图落到邻近有效块并保留文档。

### 8.2 首版语法与编辑矩阵

| 语法/内容 | 排版展示 | 直接编辑 | 源码保真与边界 |
|---|---|---|---|
| 段落、空行、软/硬换行 | P0 | P0 | 原有换行语义保留；Enter 新段落，Shift+Enter 明确硬换行 |
| ATX 与 Setext 标题 | H1–H6 | P0 | 保留原有标题形式；改变级别时仅重写该标题所需定界符 |
| 粗体、斜体、删除线 | P0 | P0 | 未改动内容保留原 `*`/`_` 选择；交叉或未知定界解析原样保留 |
| 行内代码 | P0 | P0 | 修改内部含反引号时只调整该节点必要围栏长度 |
| 无序/有序列表、嵌套列表 | P0 | P0 | 保留原项目符号与有序起始数；缩进/反缩进按当前节点结构修改 |
| 任务列表 | 原生勾选框 | P0 | 勾选只修改任务标记；不改正文、缩进或其他任务 |
| 引用、分隔线 | P0 | P0 | 结构操作局限当前块；分隔线作为可整体选择的节点 |
| 普通/自动链接、引用链接 | P0 | 文本及链接浮层 | 保留引用式写法；修改引用目标只改相应定义；悬停可查看地址 |
| 围栏与缩进代码块 | 原生等宽编辑，语法高亮 | P0 | 内容作为正文的一部分；不运行代码，不格式化整个文件 |
| GFM 管道表格 | 表头、对齐与单元格 | P0 | 支持简单矩形表格，无合并单元格、嵌套块和任意 HTML 表格 |
| 本地/相对路径图片 | P0 | 地址、替代文本浮层 | 修改只更新图片节点；不把图片转为新资产或上传 |
| 远程图片 | 占位、按需加载 | 地址、替代文本浮层 | 默认加载规则以 SETTINGS 为准；失败保留原链接 |
| 原始 HTML | 惰性、原样文本块 | 转源码编辑 | 不执行脚本，不假称浏览器级 HTML 排版 |
| 数学 `$…$` / `$$…$$` | 保留原样内容 | 转源码编辑 | 首版不承诺数学排版；不能吞掉定界符 |
| Mermaid 围栏 | 代码块展示 | 编辑代码文本 | 首版不承诺图形渲染 |
| 脚注、自定义容器、未知方言 | 可识别则展示，否则原样块 | 源码入口 | 未支持结构的原文和顺序必须完整保留；不能删掉未知节点 |

“原样块”显示原始内容和局部“编辑源码”动作；它不是错误，也不是偷偷转换为普通段落。选择整个原样块可以明确删除/剪切，普通相邻文字编辑不能改变块内部。

### 8.3 直接编辑规则

| ID | 规则 |
|---|---|
| FR-MD-04 | 在标题或段落中输入就是修改可见正文。段落 Enter 拆分为两个段落；列表非空项 Enter 插入同级项，空项 Enter 退出当前列表层；Backspace 在块首执行可预测的合并/降级，一次操作一事务。 |
| FR-MD-05 | 格式动作作用于当前选择或后续输入样式；源码补齐必要定界符。用户直接输入 Markdown 标记可在稳定节点边界转为结构；IME 未确认前禁止进行结构变换。自动转换可以一次撤销回原始输入。 |
| FR-MD-06 | 点击任务框直接修改该项状态；选中文字和点击框具有不同命中区。键盘能够聚焦并切换任务框；文本输入焦点不能被每次点击永久夺走。 |
| FR-MD-07 | 简单表格可编辑单元格、插入/删除行列、切换列对齐。Tab/Shift+Tab 移至相邻单元格，末格 Tab 新增一行；Enter 移至下一行同列，首版不在单元格内插入块级换行。删除表头时首个正文行升为表头；删除最后一行或最后一列时移除表格并保留可输入空段落。新行/删除列是单一事务，撤销完整恢复。单元格文字修改仅 patch 该单元格；结构变化可重排当前表格区域。 |
| FR-MD-08 | 代码块内部 Enter 保持在代码块，Tab 插入代码缩进；离开块由方向键越过边界或“退出代码块”动作完成。后者移至后续可编辑块开头，仅在文末无目标时插入空段落。语言选择只改变围栏语言标记，保留其他可识别信息。不因闭合围栏字符被输入而丢弃后续正文。 |
| FR-MD-09 | 同文档可一组源码、一组所见即所得，并排独立编辑；每次修改传播到其他视图。提供可开关的同步滚动，按源范围到渲染块映射，不采用简单百分比；主动滚动一侧驱动，被动侧不反向触发循环。 |
| FR-MD-10 | 所见即所得首版使用单一连续选择。执行多光标/矩形选择命令时先原位转源码，映射已有选择，再执行该命令，给一次状态提示；这些能力完整可达，不能静默不支持。已有多个源码光标切排版时保留主选区，并将“排版视图使用主选区”提示一次；仅在文档 revision 未变化时，返回源码可恢复原视图的多选状态。 |
| FR-MD-11 | 普通复制导出可见文字，并可附 HTML/Markdown；“复制 Markdown”要求非空选区（整篇可先全选），经 SourceMap 取得对应的最小连续源码片段，无法可靠映射则说明并给源码入口，不猜测序列化。向所见即所得粘贴优先纯文字，明确选择“粘贴 Markdown”才解析结构；不得将外部复杂 HTML 直接无损编辑的能力写进首版。 |
| FR-MD-12 | 图片文件拖到正文的明确插入指示线后，以文件路径引用插入；从未保存文档插图先使用绝对路径，另存时提供转换为相对路径的明确选项。普通非图片文件拖放仍是打开文件。不得无提示复制、搬移或删除原图。 |
| FR-MD-13 | 渲染和源映射后台计算并带 revision；只采用最新完整映射。短暂解析失败时保留最后稳定块与正在编辑的原文，不能显示空白正文。超预算后提示转源码或手动刷新，原文始终可达。 |

## 9. 设置、命令和 Zen

FR-SET-01：设置是普通可关闭标签。左侧分类为常用、编辑器、外观、文件与恢复、Markdown、窗口与标签、快捷键；搜索跨分类返回设置名称与匹配项。所有配置值以 SETTINGS 表为唯一来源。

FR-SET-02：设置即时保存；需要重开文件、重启或仅作用于新视图的项目在该项旁明确标注。无效数字/字体/正则不得覆盖最后有效值。恢复默认按单项执行；批量恢复需列明范围。搜索无结果时有清空查询动作，不显示空白页。

FR-SET-03：命令面板显示命令名称、分类、可用性和当前快捷键。禁用命令说明原因。快捷键编辑显示上下文冲突，不覆盖系统保留组合；输入法组合期间不将候选操作录成应用快捷键。

FR-ZEN-01：进入 Zen 按设置隐藏活动栏、侧边栏、标签栏、面包屑和状态栏，保留当前编辑视图与 Windows 窗口控制；默认不自动进入系统全屏。鼠标移至顶部显示退出入口；键盘按 COMMANDS 中退出命令生效。在没有内层状态时连续两次 Esc 退出；用于关闭当前弹层、查找或输入法候选的 Esc 不计入这两次。

FR-ZEN-02：退出后恢复进入前的分屏、标签、侧栏宽度和焦点。Zen 期间切换文档可通过命令入口完成，不能关闭被隐藏的其他组。来源窗口独立记录 Zen，不影响其他窗口。

|---|---|
| FR-REC-01 | 自动保存原文件与会话恢复是两个独立机制。恢复开启不意味着把文字写到原文件；自动保存关闭时 dirty 圆点保持到显式保存或恢复保存修订。`restoreOnStartup` 管启动布局，`restoreUnsaved` 管未保存正文自动挂载；关窗免提示必须满足 FR-WIN-06 的两个开关与成功落盘条件。 |
| FR-REC-02 | 每个 dirty 文档有恢复日志与周期快照；记录文档身份、基线磁盘指纹、内容修订、编码/换行与视图关系。建议持久化窗口不超过 2 秒，最终目标由技术性能文档锁定。UI 不承诺最后一次按键在掉电后必然存在。 |
| FR-REC-03 | 两个恢复开关都开启时，正常退出先完成恢复写入，再按 FR-WIN-06 决定是否免提示关闭；任一开关关闭或落盘失败均进入保存/放弃/取消流程，失败时还提供重试，禁止假装已保留。每次完整写入都可验证长度/校验值，半写记录可丢弃到最后有效修订。 |
| FR-REC-04 | 异常启动展示恢复摘要与文档列表，用户可恢复全部、逐项查看或放弃。默认选恢复；放弃具体记录要明确确认。一个损坏条目不能阻止其他文档恢复。 |
| FR-REC-05 | 恢复后仍 dirty，除非内容与当前磁盘完全相同。恢复期间发现磁盘已变化则保留恢复版并标冲突，不能自动覆盖。只恢复有效快照至日志末尾的完整事务，不能恢复半个多光标操作。首版保证内容、编码/换行、dirty 和视图关系，不要求跨进程恢复完整旧 undo 历史；恢复内容作为新会话基线，之后的编辑正常撤销。 |
| FR-REC-06 | 用户显式“不保存”关闭最后视图时，写入放弃标记并清除可自动恢复状态；下次启动不能把明确放弃的内容又弹回来。关闭单一副本不放弃其他视图的文档。 |
| FR-REC-07 | 不扫描或分类用户文字的“敏感性”，不根据内容改变保存、恢复或记录策略。诊断按事件与状态工作；任何用户主动导出诊断的流程与正文导出分开定义。 |

## 11. 大文件与性能体验

FR-LARGE-01：是否进入大文件模式同时考虑字节数、行数、最长行和预计布局成本，阈值与设置见 SETTINGS/技术方案。默认达到 **≥20 MiB** 触发建议的预警与渐进处理，不是自动只读阈值；达到 **≥200 MiB** 触发超大文件选择提示；任一逻辑行达到 **≥20,000 Unicode scalar（标量值）** 触发该行保护。三个阈值均含等号，分别按文件字节数和逻辑行标量数测量，不将 UTF-16 码元数误当字符数。判断依据与当前降级项在状态入口可见，不能偷偷限制编辑而让用户以为是故障。

FR-LARGE-02：加载有可取消进度，先提供首屏。加载未完成时禁止对不完整正文保存覆盖原文件；可以关闭、取消或新建其他文件。源码大文件模式可减少高亮、自动换行与全文装饰，并保留基础选择、复制、定位和搜索。所见即所得优先使用块级增量与虚拟化，暂缓非活动/离屏的昂贵计算；复杂度超限时给可取消的优化/加载提示，由用户主动选择“临时使用源码”。不能无提示把默认所见即所得变成源码或只读预览。

FR-LARGE-03：建议以 1/10/100 MiB 覆盖常规与大文件测试，1 GiB 做探索性压力测试，不把“任意大小都流畅”写成承诺。长行样本独立于总大小测试；用户可明确尝试启用高成本能力，失败能退回稳定模式。

FR-LARGE-04：搜索、解析、高亮和恢复任务均可调度/取消；输入与光标响应优先。每次工作带 revision，落后结果不绘制到新内容上。不能靠每键传递整篇字符串、同时保留多个完整副本来声称已完成大文件支持。

FR-PERF-01：原生实施必须记录冷/温启动、输入到呈现、帧间隔、首次及全量搜索、取消响应、内存峰值、加载和保存响应；报告 p50/p95/p99、样本数及失败次数。实际硬件、OS build、DPI、文件生成种子、文件规模、编码与行结构固定。已接受目标、新增建议预算及具体测量方法由 PERFORMANCE_PLAN 分开定义，未经通过前不写进宣传页。

## 12. 状态模型、辅助功能与质量门槛

文档状态可以组合，不能只做一个互斥字符串。例如 dirty + 外部冲突 + 只读可同时存在。实施至少表达：加载中、clean、dirty、保存中、保存失败、只读、外部冲突、源文件缺失、恢复中、恢复失败、大文件降级。状态的优先级是阻止数据丢失的错误优先于普通进度；不要用持续 toast 堆叠同一错误。

FR-ACC-01：所有图标按钮有可访问名称；Tab 顺序按视觉流程；列表/树使用箭头导航；焦点始终可见。命令面板提供鼠标不可用时的完整主要路径。屏幕阅读器能获知文件名、修改状态、当前模式、查找计数和表格单元格。

FR-ACC-02：正文、辅助文字、图标、选区与搜索色在浅色/深色和 Windows 高对比下分别验证。状态不只靠颜色表达。尊重系统减少动画、光标闪烁/高对比设置，不在输入路径添加装饰动画。

FR-ACC-03：缩放不使控件重叠，1920×1080 100% 与 150% 为主要检查环境；最小窗口可折叠菜单与侧栏，不把文字缩小。窗口尺寸建议下限 800×560 DIP；超出屏幕时按系统可用工作区限制，不强制超屏。

## 14. 待验证事项与变更纪律

1. NSH 固定版本的原生所见即所得编辑、源映射与共享文档模型能力；现有组件不足时必须完成原生扩展验证，不能退化成只读预览交付。
2. UTF-16、GB18030/GBK 和混合换行的完整往返；NSH Editor 的 LF 归一化不能直接成为保存层行为。
3. Windows 10 x64 的实际目标 build、用户常用输入法与双显示器 DPI 组合。
4. 8 组上限、恢复周期、大文件阈值和新增分项预算由原生验证确认后锁定；已接受性能目标保留，未达标时报告差距。
5. 所见即所得的未知 Markdown 方言必须保留；若原生解析器不能给出可靠源跨度，优先补源跨度和原样块，不以整篇重序列化换取表面可编辑。

实现变更需记明涉及的 FR/AC、原因、影响及替代方案。用户已确认的所见即所得、NSH、Windows x64 与视觉结构不得在执行过程中自行更换。
