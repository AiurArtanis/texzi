# texzi 功能与界面设计规格

版本：1.0　日期：2026-11-15　适用：Windows 原生 x64 客户端

本稿将已确认概念图转成可实施的页面、组件、尺寸和状态。产品行为以 [PRD.md](PRD.md) 为准；设置与快捷键以 [SETTINGS.md](SETTINGS.md)、[COMMANDS.md](COMMANDS.md) 为唯一数据源。下文尺寸均为 **DIP**，不能当物理像素硬编码。原型演示边界见交接包说明；浏览器画面不证明原生控件或 IME 已实现。

## 2. 布局与尺寸体系

### 2.1 窗口框架

| 区域 | 默认尺寸 | 规则 |
|---|---:|---|
| 顶栏 | 高 44 | 小图标、文件/编辑/选择/查看/转到/帮助、搜索入口、Windows 控制同一行；不显示 texzi 或文件标题文字 |
| 活动栏 | 宽 44 | 上部文件与搜索，设置固定底部；图标视觉 20、命中区至少 32×32 |
| 侧栏 | 宽 232 | 可拖到 180–420；用户隐藏后内容区回收空间；最窄窗可临时收起 |
| 每组标签栏 | 高 38 | 标签、加号、分屏入口；每组独立，不设全窗共享标签行 |
| 面包屑 | 高 28 | 普通文本/源码显示路径；WYSIWYG 默认收起；可在查看菜单切换 |
| 状态栏 | 高 24 | 左侧操作/文件状态，右侧行列、缩进、编码、换行、语言/模式；项不足时合理折叠 |
| 分割线 | 视觉 1，命中 6 | 悬停强调，拖动时不改变正文文档；拖拽结束保存布局 |
| 源码内容 | 16 字号、24 行高 | 行号栏宽随最大行号动态增长；正文左右内边距 16 |
| Markdown 内容 | 16 字号、1.7 倍行高 | 可用宽度内居中，最大正文宽 760；默认水平边距 28，窄组缩至 16 |
| 编辑组 | 最小 240×160 | 建议最多 8 组；不满足最小尺寸时禁用本次分屏并提供新窗口动作 |
| 窗口 | 建议最小 800×560 | 小屏/高 DPI 以系统可用工作区为准，不造超屏无法拖动窗口 |

顶栏中未被交互控件占用的位置是拖动区；双击执行最大化/还原。菜单、搜索和窗口控制不是拖动区。保留标准窗口阴影、调整边缘、Alt+Space 系统菜单与 Snap；最大化时窗口外圆角/边缘按系统行为。Windows 10 与 11 的系统效果可以不同，不模拟 Win11 圆角以破坏 Win10 边框。

为了 Alt+Tab、任务栏、屏幕阅读器和自动化定位，系统窗口标题可仍为“活动文件 — texzi”；这不在顶栏重复绘制。产品界面不展示仓库版本、框架名称、性能指标或原型提示；原型审阅说明放在产品窗口之外。

### 2.2 窄窗口策略

宽度不足时依次缩短搜索入口、收起面包屑中间路径、显示标签溢出列表；必要时将菜单收为菜单按钮。不能缩小正文或界面字号来塞满宽度。设置行在主区小于 600 时改为标签在上、控件在下；分屏不能变成横向不可达区域。滚动条和模式开关始终可达。

### 3.2 语法颜色

| 类别 | 浅色建议 | 深色建议 | 规则 |
|---|---|---|---|
| 普通标识符/标点 | 正文色 | 正文色 | 不给每个标点上色 |
| 关键字 | `#6943A5` | `#C7A4EF` | 依语言 tokenizer，不做语义分析 |
| 字符串 | `#267346` | `#A8D7A2` | 与注释明显区分 |
| 数字/常量 | `#955A16` | `#E4BD83` | 不使用警告图标或波浪线 |
| 函数名 | `#3267B0` | `#91BDF5` | tokenizer 能区分时使用 |
| 类型/属性 | `#206C86` | `#82CEDD` | 不承诺 LSP 语义分类 |
| 注释 | `#656E79` | `#A0AAB8` | 保证可读，不淡到不可辨认 |
| Markdown 定界符 | 次级文字色 | 次级文字色 | 只在源码显示；正文不残留无意义标记 |

最终在目标字体、字号和主题上验证正文/必要标签至少 4.5:1、控件边界和焦点至少 3:1 的对比目标。上述色值是实现起点，实际渲染不达标时调整 Token 而非逐页打补丁。

### 3.3 字体、间距与动态

- UI：`Segoe UI`，中文回退 `Microsoft YaHei UI / Microsoft YaHei`，系统无衬线；默认 14。
- 源码：`Cascadia Mono, Consolas`，中文由系统回退；默认 16×1.5=24 行高。不强制安装字体，不假设机器已有 Cascadia。
- Markdown：中文无衬线正文；H1 24/34，H2 20/30，H3 18/28，H4–H6 16/27 并以字重区分。标题上下间距 24/12；段落间距 12。
- 间距使用 4/8/12/16/24/32。设置区段间距 24，普通控件高 32–36；行式设置通常高 52–64。
- 控件圆角 4；窗口圆角交给系统。只在菜单、轻量浮层使用小范围阴影；正文和设置不铺卡片阴影。
- 悬停/侧栏显示可使用 80–120 ms 过渡；输入、光标、选区与查找导航直接响应。减少动态效果时取消过渡与滚动插值。光标闪烁遵从系统或用户常亮设置。

## 4. 页面 P01：主编辑界面

### 4.1 顶栏与活动栏

菜单使用原生菜单交互：Alt 聚焦，方向键移动，Esc 逐层退出。每个动作来自命令注册表，因此菜单、快捷键和命令面板可用状态一致。

顶栏搜索是“搜索文件或命令”的入口，不暗示当前文档查找。点击打开居中浮层：默认快速打开文件，输入 `>` 进入命令；文件内查找保留在活动编辑组。搜索入口有放大镜、提示语和键盘焦点，空闲态无厚重边框。

活动栏只有文件、搜索和底部设置。活动项由蓝色侧线、轻底色和可访问状态共同标记。切侧栏不更改活动文档；再次点击活动项收起侧栏。不存在 Git、终端、调试或插件入口。

### 4.2 文件树

顶部标题“资源管理器”，右侧按悬停或键盘焦点显示新文件、文件夹操作。行高 28，图标 16，嵌套缩进 16。展开箭头命中区与文件名称不同；选中行用浅蓝底，未聚焦树使用淡灰选区。长名省略，悬停完整路径。

状态：加载节点显示小型进度，失败节点提供重试；权限不足有文字；根目录缺失保留根节点和重选入口。空态只显示“打开文件夹”和最近目录，不出现 IDE 项目创建流程。重命名用行内输入，Enter 提交、Esc 取消，非法 Windows 文件名就地报错。

### 4.3 标签与组头

标签高 38、建议宽 104–220。活动标签白底与 2 DIP 蓝底线；非活动标签使用窗框底；预览斜体；dirty 圆点直径 6；固定图标 14。关闭按钮命中区 24×24，dirty 标记与关闭按钮同时可见，不在悬停时把 dirty 擦掉。

拖动显示标签浮影与明确落点；组中心移动、边缘切分，不靠猜测。关闭组按钮和关闭文档按钮在语义上区分；组仅有一个标签时仍按 PRD 的最后视图规则处理。标签右键菜单包含固定、移至组/新窗口、关闭当前/其他/右侧/全部、复制路径、在资源管理器中显示。

### 4.4 源码编辑面

逻辑行号按最大位数留宽，续行不重复行号；当前行弱底色，主插入光标 2 DIP，额外光标同色。多光标状态栏显示“n 个光标”，不要只显示一个行列造成误解。选区拖过可视边缘自动滚动，移动与内容渲染同一坐标系统。

缩进指示线和空白标记可配，视觉强度低于正文。右侧滚动条默认窄轨，悬停扩大命中；保持系统可用性与高对比。滚动条可绘制搜索匹配位置点，不增加 minimap。折叠按钮仅在有意义的语言/区域显示。

### 4.5 状态栏

左侧优先显示保存失败、外部变化、恢复或大文件状态，其次显示“就绪/已保存”。右侧项目：位置或多光标数、缩进、编码、换行、语言、Markdown 模式。点击编码、换行和语言打开相应选择菜单；显示当前值和待执行动作，不把“以编码重开”和“转换编码保存”合并成一个模糊动作。

保存中可显示细小进度与“保存中”；保存失败保持错误文字和重试入口，直到处理。短成功提示不打断键入；需要用户处理的错误不能只出现两秒后消失。

## 5. 页面 P02：多编辑区域与 Markdown

### 5.1 参考三组布局

文件树不变；内容区左侧约 58%，右侧约 42%，右侧再上下各半。该比例是概念图起点，分屏树允许自由变更。每组独立标签、滚动条和焦点；活动组底线/边框明确，其他组保持正常文字对比。

打开同一 Markdown 的排版视图与源码视图是两个 EditorView，共享 Document。右上同一位置可看到各自的模式状态；修改同步到另一组，不把其滚动位置拖到活动光标。同步滚动开启时只驱动与同一文档建立链接的那一对视图。

### 5.2 所见即所得正文

排版态没有源码行号。正文右上 `>_` 为 32×28 的轻按钮，距离右/上边缘 16/12，固定于视图，不随正文滚走。可访问名称为“切换到源码”；源码态保持同一按钮位置，按下态并改为“返回所见即所得”。模式信息也在状态栏，不让用户仅靠图标猜。

正文的标题、段落、任务列表、代码和简单表格是可编辑的原生节点；光标与选择进入实际内容。选中文字时可出现轻量格式浮层（粗体、斜体、删除线、行内代码、链接），不固定一整条 Ribbon。浮层须避开 IME 候选；键盘用户有对应命令路径。

任务框视觉 16、命中 24；选中填 accent 加白色对钩，未选中为 1 DIP 边框；更改不重新排列其他内容。表格行高至少 34，单元格内边距 8；活动单元格细焦点边，表格结构动作按焦点显示，离开后收起。

删除表头后首个正文行升为表头；删除最后一行或列后显示可输入空段落，不留无法聚焦的表格壳。结构操作提供单次撤销。表格菜单与命令面板使用同一命令注册，不只依赖鼠标按钮。

代码块用淡底与 1 DIP 边框，字号与源码规则一致；顶部轻量语言标记与复制按钮在悬停/焦点时可用。它是代码文字编辑区，不出现运行、补全或诊断。代码块横向滚动不带动整篇正文横移。

“退出代码块”将焦点放到后续可编辑块；仅在文末没有目标时增加空段落。“复制 Markdown”只对非空选区启用，无法准确映射原文时提供源码入口；不将不可靠的重建结果标为原文。

原样块显示原文、类型和“编辑源码”，不能覆盖一大段空白。未知节点被选中时展示整体边框；删除/剪切作为明确事务。HTML、数学与 Mermaid 的范围以 PRD 矩阵为准，不将未实现的排版画成默认产品承诺。

### 5.3 切换与同步反馈

切模式时保留当前块/光标锚点，不滚回文首；短布局等待可在右上出现活动指示，不遮挡整个窗口。大文档转换提供可取消状态和返回源码动作；正文仍可恢复到最近稳定源内容。

同步滚动通过组头轻量链条按钮或查看菜单控制。开启态有文字提示“同文档同步滚动”；不同文档禁用并说明。图片加载或窗口宽度改变保持段落锚点，不突然跳到旧百分比位置。

多光标/矩形命令在排版态执行时，原位切源码并给一次不阻塞状态提示：“此操作已切换到源码”。切回排版时只显示主选区的约束同样明确。原型即使只能演示提示，也不得标成已经实现原生多光标。

## 6. 查找与替换组件

默认宽 392，右上距边 12；窄组按可用宽度布局，开关放第二行，不截断关闭按钮。查找栏悬浮于编辑视图但不改变正文宽度；保留右上 `>_` 的独立命中区，必要时查找栏位于其下。

| 元素 | 行为/状态 |
|---|---|
| 展开箭头 | 展开替换行；排版态展开时先切源码并重算结果 |
| 查询输入 | 支持多行内容，以可见换行标记/展开输入呈现；无结果不清空用户查询 |
| 范围标签 | 明确“正文”或“源码”；选区内则补充“选区内”；不是隐蔽 tooltip |
| `Aa` / 全字 / `.*` | 图标有中文可访问名与按下态；开启正则触发源码语义，不沿用正文命中计数 |
| 计数 | 完成时“2 / 7”；扫描时“已找到 7 项…”；超限/取消明确显示，不伪造最终数 |
| 上/下一个 | 可键盘访问；边界回绕给短状态提示 |
| 替换输入 | 字面模式与正则模式有明确说明，捕获组语法可展开帮助 |
| 替换当前/全部 | 只在查询有效、有匹配且文档可写时启用；准备中显示取消 |
| 关闭 | 关闭面板，保留最后选区；Esc 优先关闭内层错误/菜单后关闭查找 |

错误显示在查找栏内：正则语法错误、预算超限、替换组不存在、文档变化需重试。全部替换完成用状态文字“已替换 n 处”，撤销保持单次操作。所见即所得查找可高亮分散的可见文字跨度，不能给 Markdown 语法标记增加排版态的不可见命中。

文件夹搜索位于侧栏：查询与选项、包含/排除条件、文件分组结果、底部状态。点击结果在正文定位；一个文件内多个命中折叠归组。P0 不显示可点击的“跨文件全部替换”，避免画出尚未承诺的能力。

## 7. 页面 P03：设置

设置以标签打开，重开时聚焦已有设置页，不重复创建。设置页活动时左侧从文件树切换为设置分类；切回文档恢复原文件树展开状态。侧栏仍为 232，分类行高 36、图标 18。

顶层分类保持概念图的七项：常用、编辑器、外观、文件与恢复、Markdown、窗口与标签、快捷键。查找、大文件、Zen 可以作为相应分类内的分组及搜索别名，不新增一长列顶层导航。

主区左上页标题 20/28；右上搜索宽 280–360。下面使用可滚动的行式表单，内容边距 32，最大内容宽 1040。设置名与有必要的说明放左，控件放右（建议宽 240）；一条细分隔线区分相邻设置，区段标题间隔 24。

### 7.1 常用页初始内容

| 分组 | 可见项目 | 初始状态来自 SETTINGS |
|---|---|---|
| 外观与文字 | 主题、源码与代码字体、字号 | 跟随系统；Cascadia Mono/Consolas；16 DIP |
| 编辑与 Markdown | 纯文本换行、源码行号、Markdown 默认模式 | 开；开；所见即所得 |
| 文件与恢复 | 自动保存、恢复上次会话 | 关闭；开启 |

“自动保存”下的必要说明为“自动写入原文件”；“恢复上次会话”的必要说明为“包含未保存的临时文本”。这两条说明用于避免误解，不扩展为大段宣传。图中“自动换行”在正式界面明确对象，不误导成同时改变所有代码视图。

### 7.2 设置组件状态

开关轨道建议 36×20，命中行/标签也可切换。下拉使用 32–36 高，可输入字体支持字体可用性提示。数值步进器有最小/最大与单位，失焦/Enter 验证；无效值显示就地错误，保留最后有效值。恢复默认用行尾菜单，不在每行放醒目按钮。

设置有“用户 / 当前文件夹”范围入口，后者存本机工作区偏好，不擅自向用户项目写配置文件。被更高优先级覆盖的值显示来源和恢复路径。保存失败状态不能写“设置已保存”；磁盘失败时保留当前运行值与未持久化提示。

搜索结果显示分类小标题、命中的完整设置行和“清除搜索”；无结果显示原查询及清空按钮。依赖未满足的控件置灰，并用短文字说明依赖；不要只降低透明度。

快捷键页有命令名称、当前键、来源、上下文、编辑与恢复默认。录制时清楚提示正在录制；系统键/同上下文冲突显示阻止或明确解决方案，不无声覆盖另一个命令。命令搜索与设置搜索可以共用查询入口，但结果类型不同。

## 8. 浮层与异常页面

### 8.1 快速打开/命令面板

置于窗口上部居中，宽 min(600, 窗宽−48)，输入高 40，结果行高 32，最多显示约 10 项后滚动。文件结果展示名称与精简目录，命令结果展示名称、快捷键和禁用原因。Esc 返回原焦点和选区；Enter 执行不产生额外正文输入。输入法候选优先于结果导航。

### 8.2 保存与关闭

使用 Windows 原生打开/保存文件对话框，支持多选和系统目录习惯。最后一个 dirty 文档关闭对话框显示真实文件名和路径，按钮“保存 / 不保存 / 取消”；默认聚焦保存或取消，不能将不可逆放弃作为 Enter 默认。

关窗可以免提示的条件严格为 `session.restoreOnStartup && session.restoreUnsaved && snapshotFlushSucceeded`。任一条件不满足时，界面进入保存/放弃/取消流程；落盘失败额外提供重试。该条件不适用于显式关闭最后一个 dirty 标签，后者始终显示关闭确认。设置页两个恢复开关的说明需让用户能够理解这一差异。

批量关闭列出每个独立文档一次，勾选保存项，未选项明确为放弃；取消保留未关闭状态。保存成功才关闭对应视图；任一失败在列表定位错误，不继续隐藏失败文件。

### 8.3 外部修改与比较

活动文档顶部非模态信息条高约 40，文本“文件已在外部修改”，动作“比较 / 重新加载 / 另存副本 / 覆盖”。内容仍可读可复制；覆盖和重新加载有明确确认及最新版本校验。

上述冲突动作适用于 dirty 文档。clean 文档按 `files.externalChange`：默认 `reloadClean` 自动重新加载并显示短提示；`ask` 即使 clean 也显示“文件已在外部更新”的信息条及“重新加载 / 稍后”，用户确认前不改变缓冲、光标或历史。实际重载后才清除旧撤销历史。

比较页面为当前缓冲与磁盘版本的只读两栏，注明版本来源；行级差异同时用标记和文字解释，不只依赖红绿。P0 不提供复杂三方自动合并。关闭比较返回原文档与原焦点。

### 8.4 恢复中心

异常启动显示宽约 680 的恢复摘要，列文档名、原路径/临时文本、最近可恢复时间、状态。支持查看、恢复选中、恢复全部、明确放弃。损坏条目显示可恢复范围与原因，其余条目可独立继续。

恢复完成以 dirty 标签打开；与当前磁盘冲突的标签带同一外部变化提示。没有恢复条目时不显示空恢复中心。正常恢复只需简短状态，不每次启动弹大对话框。

### 8.5 编码与二进制

编码不确定页面展示可选择编码及只读样例，选择后重新解码预览；用户确认前不修改源文件。不可表示字符的保存错误显示数量、示例位置和“改用 UTF-8 / 返回编辑”，替代转换是明确的次级操作。

二进制提示展示文件名、大小与“以文本只读打开 / 取消”。UTF-16 文件先识别 BOM/编码，不能一见 NUL 就显示二进制错误。源文件缺失状态提供“重建文件 / 另存为”，不能用普通保存成功提示掩盖重建。

## 9. 大文件页面与进度

打开大文件时在标签/内容顶部显示加载进度、取消按钮和已可用范围；不在整窗覆盖阻塞遮罩。加载未完整时保存不可用并解释。进度有真实阶段“读取 / 解码 / 建立索引 / 可编辑”，不能无限旋转而无取消。

大文件入口显示当前暂缓的高亮/软换行/排版项和恢复动作。默认文件大小达到 **≥20 MiB** 触发建议的预警/渐进处理，不是强制只读线；100 MiB 普通文本与 Markdown 源码仍需按性能方案验收。Markdown 复杂度触发渐进处理时，保持可取消加载与原生编辑目标；“临时使用源码”是用户主动动作，不能静默把默认所见即所得改成只读预览。

默认文件大小达到 **≥200 MiB** 或资源不足时提供“只读查看 / 尝试编辑 / 取消”，清楚区分能力；不把只读流式查看算作完整编辑通过。逻辑行达到 **≥20,000 Unicode scalar** 时仅对受影响行暂停高亮/换行，并显示状态入口，不改变原文的换行字符。界面阈值文案统一写“达到”，实现使用包含等号的比较。

## 10. Zen 与焦点恢复

进入 Zen 后按用户设置隐藏侧栏、活动栏、标签和状态栏；当前编辑区扩大，其余组仅隐藏，不销毁。顶栏保留 Windows 控制与顶部唤出区；默认不进系统全屏。鼠标到顶部出现轻量“退出 Zen”，键盘也有明确路径。

关闭查找、菜单或输入法候选优先消费 Esc；无内层时执行退出规则。不能一个 Esc 同时取消候选、关闭查找和退出 Zen。退出恢复进入前的可见组件、分屏比例、活动文档与焦点，不把焦点放到已隐藏按钮。

## 12. 实施与视觉验收要求

1. 原生验收截图至少覆盖主界面、三组布局、所见即所得/源码切换、普通查找/替换、设置、Zen、外部冲突、恢复与大文件。
2. 1920×1080、100% 与 150% DPI 各检查浅色；深色/高对比检查选择、光标、搜索、菜单和表格；双显示器移动验证真实坐标。
3. 用键盘完成打开文件、编辑、查找替换、切模式、切组、设置及关闭；菜单/浮层结束后焦点回到发起位置。
4. 排版态普通查找必须留在排版态；正则或替换切源码要更新范围文字和计数，不沿用旧高亮。
5. 图片加载、字体更改、侧栏宽度与分割线拖动后，阅读锚点稳定；不得出现一帧先空白再回文首的跳动。
6. 所有界面数据、提示和能力状态真实：没有实际原生实现的功能不得以“已支持”状态交付；对应可执行检查见 [ACCEPTANCE.md](ACCEPTANCE.md)。

辅助功能参照 [Windows accessibility guidance](https://learn.microsoft.com/en-us/windows/apps/design/accessibility/accessibility)；DPI 与系统窗口行为参照 [High DPI Reference](https://learn.microsoft.com/en-us/windows/win32/hidpi/high-dpi-reference)。数值和布局是本方案设计基线，需在目标 NSH 构建上验证。
