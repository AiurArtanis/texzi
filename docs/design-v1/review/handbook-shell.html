本次设计的关键决定

Markdown 默认直接编辑排版正文，右上 >_ 原位切源码。两种模式使用同一文档和撤销历史；切换本身不改写原文。Windows 窗口菜单融入单行外框，左上不重复显示应用标题。

20 MiB 是建议的渐进处理阈值，不能据此自动变成只读。100 MiB 性能目标明确针对普通文本与源码；复杂富文档单列验证。

交付的完成边界

本手册提供完整设计和浏览器交互原型，原生 NSH 客户端由下一阶段实施团队开发。纯逻辑测试已实际运行；本地浏览器渲染检查受当前环境限制，真实浏览器与 Windows 原生验收保持 NotRun，详情见验证报告。
