# texzi 本机开发测试包

解压全部文件后，从资源管理器双击 `texzi-app.exe`。本包内嵌 Ink Z 图标，Release 为 Windows GUI 子系统。它仍是开发候选，请只用生成的测试文档：支持严格 UTF-8/BOM 读取，保存、完整编码与恢复尚未通过；关闭未保存内容必须明确选择放弃，不能把内存编辑当成已保存。

- “源码”可直接输入 Markdown；“富文本”用于同一正文的原生编辑。组合输入尚在进行时，先确认或取消组合，再切换模式。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做；两种模式共享撤销历史。源码多选区能力保留，富文本多选及复杂位置恢复尚未完成。
- 暂不能保真处理的操作会显示原因，并保留原状态；可切到源码编辑该范围。富文本结构和数据安全功能仍在开发中，不是完整首版验收。
- 富文本上方提供“链接属性”“图片属性”“表格操作”。先把光标放到对应节点或单元格；修改前检查版本，取消不写正文，应用通过同一正文和撤销历史。属性面板过期时应取消后重开。
- 图片始终显示替代文本、原地址和加载状态。本地相对地址以测试文档所在目录解析；未保存文档的相对地址会提示无法定位。远程图片显示占位，点“加载远程图片”后才请求；失败保留原地址并可重试，不上传或搬移图片。
- HTML、数学、脚注和未知方言保留原样。对应条目“编辑源码”只定位并切换模式；“选择整块”后可明确 Delete 删除，普通块内输入和部分跨块改写会拒绝。模式切换和选择本身不改正文或 dirty。
- 光标在真实代码块中时，“代码语言”仅修改围栏语言词并保留其它信息；缩进代码不自动改成围栏。`Tab`/`Shift+Tab` 或对应按钮缩进/反缩进。“退出代码块”定位后续可编辑块，没有目标才在文末添空段；Enter 本身保留在代码块。未闭围栏的文末退出和含附加信息时清空语言会明确拒绝，不冒称全部代码边界已支持。
- 表格单元格中 `Enter` 移到下一行同列，不插入段落或正文换行；最后一行给出边界提示，末格 `Tab` 可新增行。普通段落、列表、代码块继续使用各自的 Enter 规则。
- 排版态的 `rust`/`rs` 和 `json` 围栏提供有限语法着色，不运行代码；其他语言、无语言和超限内容保持纯文本编辑。颜色跟随应用的浅色/深色主题，切主题和取着色结果本身不修改正文或撤销历史；这不代表所有语言/复杂词法已支持。
- 命令面板的 Markdown 格式、任务、代码退出及表格行列操作调用当前正文的同一事务入口。链接和代码语言打开工具栏使用的同一属性表单；选中文字可创建链接，空光标可填写链接文字后插入，原引用定义仍局部修改。表格列对齐须明确选择，插入行/列按命令表默认在当前项之后，也可在表格面板选择之前。无效上下文明确说明，不假称已完成。
- “段落样式”可在当前独立段落/标题选择正文或 H1–H6。ATX 保留原正文拼法与关闭标记；改回正文只删除必要标记。Setext H1/H2 保原下划线形式，选择 H3–H6 时提示必要的 ATX 转换。复杂嵌套/多行转换若不能保持结构，会拒绝且保留原文，不宣称全部标题边界已完成。
- “转到”接受行或行:列，均从 1 开始，列按字素簇计数、Tab 算一列。复制行覆盖所有选区涉及的逻辑行并合并重复范围，通过同一正文事务撤销。自动换行仅作用于当前源码视图，不修改其它视图或正文。
- 源码多个选区进入排版时显示主选区并提示。纯模式往返且正文 revision、两视图位置代次均未变时恢复原多选；正文变化或任一侧真实位置变化（含离开再回来）使旧多选失效，返回源码采用当前主选区并说明。该限制不等于任意滚动/导航后可恢复旧多选；模式变化本身不新增正文或撤销事务。
- 外框为 Windows 原生菜单，Alt/方向键/Esc 操作菜单。提供标签、文件夹浏览、查找替换、命令面板、源码行号、双组视图、主题与 Zen。双组共享同一正文和撤销历史，当前最多两个组；新窗口是独立空窗口，不承诺跨窗迁移。保存项明确不可用，设置仍未接入，其余行为以本包对应的逐项验证记录为准。
- 普通查找在富文本中按可见文字查找；替换和源码行号先切到源码。目录搜索限制为严格 UTF-8 文本，并显示预算、跳过、错误与取消，不声称覆盖任意目录或完整编码。
- `Ctrl+K` 组合键等待第二键；无效第二键取消。`Ctrl+B` 在富文本中保留加粗，侧栏统一使用 `Ctrl+K Ctrl+B`。代码、未知语法与数学等原样类的边界见 `component-tests/SYNTAX-MATRIX.md`；组件通过不等于全部 GUI 交互已通过。
- 当前验证暂停全部剪贴板读写及 `Ctrl+C/X/V`，也不执行剪贴板恢复探测。此前测试未证明完整恢复原剪贴板，该缺口保留。

运行前核对 `build-identity.txt` 的 commit/run/attempt 和 `SHA256SUMS.txt`：

```powershell
Get-FileHash ./texzi-app.exe -Algorithm SHA256
$app = Start-Process -FilePath (Resolve-Path ./texzi-app.exe) -PassThru -RedirectStandardError ./startup.log
$ownedHandle = $app.Handle
$app.WaitForExit()
$app.ExitCode
```

正常关闭应退出进程。错误弹窗须确认后再检查真实退出码，不能把等待确认当作自动退出或挂死；隔离故障入口见 `STARTUP_FAILURE.md`。

本包仅面向 Windows x64 本机开发验证，使用系统 Direct2D/DirectWrite、系统字体和静态 MSVC CRT，不另装运行时。依赖许可随 `licenses/`、`sbom.json` 提供。组件测试与开发限制见 `component-tests/RICH-RUN.md`；构建成功不代表实际运行或人工验收通过。
