## 1. v1 是什么

用户双击 exe，看到的界面和三张概念图一致。能写普通文本、代码片段和 Markdown，Markdown 用所见即所得，按 `>_` 切换源码。能打开、保存文件，打开大文本不卡。

范围来源只有两处：大主教在 DECISIONS §1 确认过的 U01–U16 和已接受的性能目标，以及 11-18 补充的下一版要求。设计包自己加出来的建议值不算范围。

## 2. 做什么

按顺序交付。第一阶段做完就打一个可用包交给大主教试用，不必等第二阶段。

### 第一阶段：能用的单窗口编辑器

| # | 功能 | 做到什么程度 |
|---|---|---|
| A1 | 外壳 | 单行顶栏：图标、文件/编辑/外观、统一搜索、窗口按钮，不显示产品名。窄窗用「菜单」展开同样三组。活动栏、可隐藏文件树、标签栏、状态栏。尺寸和颜色按 DESIGN.md，支持浅色和深色。 |
| A2 | 图标与启动 | 使用柔光缎带版（轻缎 Z）图标。双击 exe 不闪命令行窗口。 |
| A3 | 菜单 | 菜单里列出的项都能用。还没做的功能不进菜单，也不放灰色占位。 |
| A4 | 文本编辑 | 输入、中文输入法、选择、剪切/复制/粘贴、撤销/重做、多光标（Ctrl+D、Alt+单击）、矩形选择、常用快捷键。默认键按 COMMANDS 设置，只实现菜单里有的命令。 |
| A5 | Markdown | 默认所见即所得，右上 `>_` 原位切换源码。支持 CommonMark + GFM 的全部块：标题、段落、强调/删除线/行内代码、链接、图片、有序/无序/任务列表、引用、代码块（带高亮）、表格、分割线。不认识的语法显示成原文块，保持原样不改写。数学公式和 Mermaid 按原 PRD 放到 P1，v1 按原文块显示。 |
| A6 | 切换保真 | 两种模式共用同一份正文和同一条撤销历史。没编辑就来回切换，文件字节保持不变，dirty 状态也不变。 |
| A7 | 代码片段 | 常用语言有语法高亮，不做其他开发功能。 |
| A8 | 文件 | 新建、打开、保存、另存为、关闭；关闭未保存文件时提示。支持 UTF-8（含 BOM）、UTF-16 LE/BE、GBK/GB18030 读写，保留原有换行风格，状态栏显示编码和换行。 |
| A9 | 保存 | 见 §3，只做这些。 |
| A10 | 查找替换 | 文件内查找和替换，支持大小写、整词、正则，替换全部可以一步撤销。 |
| A11 | 外部修改 | 文件没改动时自动重新加载。有未保存修改时提示三选一：重新加载、保留我的、另存为。 |
| A12 | Zen | 从统一搜索的命令模式或 Ctrl+K Z 进入；按两次 Esc 或点右上按钮退出，退出后布局复原。 |
| A13 | 大文件 | 9.4MB 的《十日终焉》打开、滚动、输入都流畅。超过 50MB 时自动改用源码模式并关闭高亮，状态栏给出提示。 |

### 第二阶段：补齐初始设计的工作台

| # | 功能 | 做到什么程度 |
|---|---|---|
| B1 | 分屏 | 左右或上下分屏，可以把标签拖到另一个区域。同一文件开多个视图时共用一份正文，各自保留光标和滚动位置。 |
| B2 | 多窗口 | 标签可以拖出成新窗口，未保存状态跟着走。 |
| B3 | 文件夹 | 打开文件夹，文件树导航，在文件夹里搜索文本。 |
| B4 | 设置页 | 以标签页形式打开，布局按概念图 03。只做常用的 10–15 项：主题、字号、字体、换行、Tab 宽度、默认编码、默认换行、Markdown 默认模式、自动保存（默认关）、恢复会话（默认开）、minimap（默认关）。 |
| B5 | 会话恢复 | 重新打开时恢复上次打开的文件和未保存内容。实现方式：每 2 秒把 dirty 文档的快照写到 `%LOCALAPPDATA%\texzi\recovery`。 |

## 3. 保存只做这些

| 情况 | 做法 |
|---|---|
| 已有文件 | 在同目录写临时文件并 flush，然后用 `ReplaceFileW` 替换。这个 API 会保留原文件的 ACL、属性和创建时间。替换失败时原文件保持原样，dirty 保留。 |
| 新文件 | 在同目录写临时文件，再用 `MoveFileExW` 改名。权限按目录默认继承，不做任何 ACL 处理。 |
| 失败提示 | 显示系统错误原文，加一句人话说明，按钮只有「重试 / 另存为 / 取消」。 |
| 保存时继续编辑 | 正在保存 revision N 时用户继续输入，保存完成后只有当前 revision 仍是 N 才清 dirty。 |
| 编码装不下的字符 | 提示「改存 UTF-8 / 取消」，不能默默写成 `?`。 |

**明确不做：** ACL 与安全描述符校验、owner-only 发布、临时副本可见性窗口（REPLACE-SEC-01）、模拟其他用户身份、原生故障注入、句柄连续性和 binding epoch、failure latch、quarantine、文件 ID 身份追踪、网络盘断连重连、二进制文件判定流程、恢复日志校验和半写回滚。

## 5. 代码侧怎么处理（交 Cozy）

1. **T07 改为按 §3 重写。** `files/` 下凡是服务于 ACL、身份、句柄连续性、故障注入、quarantine 的代码和对应测试，一律删除或断开。`legacy_spans` 如果只服务于逐字节保留，也一起删；判断依据是 V9，只要原编码原样回写能通过就行。目标是保存链路约 1000 行，现在约 13600 行（`files/` 9866 行加测试 3769 行）。
2. **测试按一条规则留删：** 测的是 §2/§3 里的行为就留，测已删行为的就删，测流程合规的也删，比如 probe 协议和链接命令追踪。
3. **构建：** `cargo build --release` 就是正式构建。`build-candidate.ps1` 里的工具链追踪、link 命令取证、注入失败证据可以保留，但不进 v1 门禁。
4. **README** 改写为三段：一句话介绍、怎么构建、怎么运行。

## 6. 防止第三次膨胀的规矩

1. 要新增门禁、验收项或防御要求，必须能对应到本文 §2 或 §3 的某一条，或者大主教的原话。对应不上就不加；要加，先写进本文并注明来源。
2. 评审意见里的「建议」不会自动变成阻断项。要变成阻断项，按第 1 条走。
3. 候选只对照 §4 里相关的条目验收，不建 FR→AC→证据映射表。
4. 被执行引擎策略拦截时，停下来报大主教，不换个写法重跑。
5. 同一个功能 FAIL 两轮，或者代码量超过预估 3 倍，就停下来交 Grady 归因，不继续往上加。
6. 测试禁令不能把核心功能挡在外面。剪贴板就是编辑器的核心功能，测试只在测试文本上操作，用完恢复原剪贴板内容，不能整项写成 NOT_RUN。
