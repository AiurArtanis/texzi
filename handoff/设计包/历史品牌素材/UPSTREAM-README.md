# Texzi · 轻缎Z 开发图标包

版本：1.0 · 2026-11-16

保留已选原始造型、配色、材质及内边距。无重新绘制或 AI 再生成。

## 直接使用
- Windows 应用、快捷方式与安装器：windows/app.ico（内含 16、20、24、32、40、48、64、96、128、256 像素）。
- 桌面 UI / 高 DPI：png/icon-{尺寸}.png，按实际设备像素选择；例如 24 DIP @2x 使用 48px。
- 网站：web/favicon.ico；PWA 使用 icon-192.png / icon-512.png，purpose 为 any，勿误标 maskable。
- 原始透明位图：source/master-1254.png（1254×1254 RGBA），为本包唯一母版。
- preview 为浅/深色检查图，不是透明生产资源。

PNG 使用透明 Alpha，尺寸从原始母版独立缩放，不串联缩放。ICO 各帧包含透明度。

## 注意
这是带材质的位图设计，不提供冒充矢量的 SVG，也没有可编辑的分层 PSD。16–24px 下材质细节自然简化，轮廓与配色保留；不建议作为要求单色的状态托盘图标。不要给图像再次加圆角裁切或自动去背景。墨流的暖瓷底板属于图标本身，应保留。

原图由此前 AI 图像生成得到，本包只做格式与尺寸导出；未进行商标检索或注册评估。sha256.txt 用于文件完整性检查，不代表授权认证。
