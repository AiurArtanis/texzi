# texzi 原型运行与审阅说明

## 1. 交付形式

prototype/index.html 是可独立打开、无网络资源依赖的完整HTML文件。prototype/src/ 保留可维护的HTML/CSS/JavaScript，tools/build.py将两个权威JSON目录一并编入原型。单独提供的texzi-prototype.html与打包版本一致。

原型依据确认后的三张概念图，采用单行菜单顶栏、浅灰侧栏、白色正文、克制的蓝色焦点。顶部“设计审阅 / 场景 / 原型说明”在产品窗口外，是评审工具，不是未来产品界面的一部分。

## 2. 运行方式

Windows上双击start-preview.cmd，或用桌面Edge/Chrome打开prototype/index.html。无需Node、Python、Rust或NSH。浏览器如果拦截部分快捷键，使用产品菜单完成同样动作。

需要HTTP环境时，安装Python后运行：

~~~powershell
py -3 tools\serve.py 8765
~~~

浏览器访问脚本打印的本地地址。该脚本只绑定127.0.0.1，不发布到公网；保持命令窗口运行，退出后服务停止。单文件本地打开和HTTP方式分别拥有浏览器存储空间，演示会话不会自动互通。

建议1280×800或更大的桌面视口、100%缩放。设置中的DIP是正式客户端单位；浏览器原型使用CSS px近似布局，不用于DPI合格判定。

## 3. 真实实现、部分覆盖与演示

| 能力 | 原型中实际执行 | 明确边界 |
|---|---|---|
| 普通文本 | 输入/选择/复制粘贴、dirty、单文档快照undo/redo | 不是Rope；最多120历史快照；撤销选择恢复与大文件优化不是完整实现 |
| Markdown编辑 | 段落、标题、列表、任务、表格单元格、代码块基础内容可直接改；回写当前块 | 基础自制解析器；不是完整CommonMark/GFM编辑内核；跨块结构编辑、粘贴复杂结构、插删表格行列等见PRD而非声称全部已做 |
| 模式切换 | >_ 原位切WYSIWYG/源码，不运行全篇serializer，保留相同文档与历史 | 光标/滚动锚点映射是近似审阅效果；正式双向映射须另实现 |
| 未知语法 | Front matter、特殊块以原文块呈现，切模式不重写 | 数学、Mermaid、任意HTML不会在此执行；图片以原文保留 |
| 查找替换 | 字面/大小写/全字/正则、上下项、单次/全部替换、一次undo | JS RegExp后台Worker、500ms超时、最多20,000匹配；不完整搜索阻止替换；正式PCRE2有独立兼容契约 |
| 正文搜索 | WYSIWYG普通查找基于可见正文文本；正则/替换切源码 | 高亮依赖浏览器CSS Highlights；不支持时计数仍可用，需用源码定位 |
| 多光标 | 相同内容多选后同步插入/退格/粘贴；Alt点击基础光标 | 不覆盖完整矩形选区、grapheme删除、IME多光标语义；不能用于Unicode可靠性验收 |
| 文件/文件夹 | 选择导入UTF-8文本、列示文件、下载保存副本 | 每文件≤5MiB、最多100文件；不覆盖原文件、无目录监听；树结构为审阅简化 |
| 标签/分屏 | 预览转常驻、关闭、固定、跨组拖动、同文档内容更新、分割线调整 | 最多3组；原生任意Dock布局/屏幕边缘分窗未实现；标签完整溢出/无障碍需验收 |
| 新窗口 | 打开浏览器演示窗口并传递当前文档 | 不提供真实跨窗口实时DocStore、进程协调或Windows窗口拖拽 |
| 设置 | 63项可查阅与存值；主题/字号/换行/行号/正文宽度等即时影响 | 未实现的原生配置仅保存值并提示；依赖锁定、快捷键录制与完整冲突UI以文档为准 |
| Zen | 收起干扰区域、当前编辑组专注、两次Esc/按钮退出 | 不证明Windows全屏、多个显示器和系统快捷键正确 |
| 恢复 | 浏览器localStorage保存演示内容并重新打开 | 不是磁盘事务journal；有浏览器配额/私密模式限制；不保证故障恢复窗口 |
| 外部变更/只读/保存失败 | 可交互横幅、比较、选择保留/重载和另存入口 | 事件来源由“状态演示”触发，不是真实文件监视和权限错误 |
| 大文件 | 展示可编辑、渐进处理状态和策略说明 | 400行左右小样本明确标示，不是实际100MiB文件 |
| 中文IME/性能 | 使用浏览器自身输入机制 | 不证明NSH TSF、候选窗、DPI、启动/内存/100MiB等目标 |

## 4. 六条核心评审任务

| 编号 | 操作 | 应观察到的行为 |
|---|---|---|
| P01 日常编辑 | 主界面“今日待办.txt”添加一句话，编辑菜单撤销，再重做 | dirty圆点随保存点变化，正文修改可恢复 |
| P02 模式一致 | 分屏编辑，勾选任务；按>_查看对应任务标记，再切回 | 同一内容两种表示，切模式本身没有新undo |
| P03 搜索范围 | Markdown所见即所得中查“编辑”；启用正则或展开替换 | 起初范围正文；随后同区域切源码、标签变源码、重新计数 |
| P04 多区共享 | 从一个已打开文档点击拆分；编辑一侧再在另一侧撤销 | 两侧源内容一致、共用历史；视图可各自滚动 |
| P05 配置与专注 | 设置切深色与字号；返回正文进入Zen再退出 | 主题/文字立即变化，Zen恢复原有编辑组 |
| P06 异常决策 | 状态演示外部变更→比较→保留；保存失败→另存；恢复→保留 | 明确知道事件是模拟，操作结果/dirty不含糊 |

## 5. 可用的原型快捷键

原型常用按键包含Ctrl+P、Ctrl+Shift+P、Ctrl+F/H、Ctrl+N/O/S、Ctrl+Z/Y、Ctrl+,、Ctrl+反斜杠、Ctrl+D、Ctrl+Shift+L、Ctrl+G、Ctrl+Tab、Ctrl+1/2/3、Ctrl+K Z与Ctrl+K Ctrl+B。浏览器可能先处理其中一部分。

Markdown正文有选择时Ctrl+B/Ctrl+I应用基本格式。普通文本/非正文焦点Ctrl+B切侧栏；组合输入期间不抢占IME。模式按钮没有新增默认键。**115项正式命令表不是原型已全部绑定的清单。**

## 6. 演示数据与文件

初始样本均为人工编写的公开演示文字，不包含用户私有文件。用户自行导入的内容只在当前浏览器本地存储；原型代码不发网络请求、不上传正文、不做敏感度判断。导出通过浏览器下载目录保存副本，原始文件不被覆盖。

“帮助 → 重置演示数据”清空本原型的演示会话与设置并恢复样本。它不删除导入文件的本机原件。浏览器私密模式、清除站点数据或配额不足都可能丢失演示会话，正式可靠性方案应阅读TECHNICAL_DESIGN而不是复用此机制。

## 7. 构建与测试

~~~powershell
py -3 tools\build.py
node tests\core.test.cjs
~~~

tests/browser_smoke.py 是真实浏览器自动化脚本；需在具备Playwright与浏览器的环境运行。当前交付环境的浏览器连接/本地页面权限受限，未完成真实浏览器渲染验收；准确状态见VERIFICATION。不得把纯函数测试通过转换为“所有交互已测试通过”。

修改权威设置/命令JSON后必须重新运行build.py。没有原生安装器、Cargo工程或生产数据迁移程序藏在此原型中；实施团队按HANDOFF创建正式工程。
