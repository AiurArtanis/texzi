# texzi 视觉依据

本文件记录已确认概念图的视觉决策。完整状态与组件行为以 docs/UI_SPEC.md 为准。

## 模式

Operate：用户在完成编辑任务，界面应稳定、易扫描，内容优先。

## 结构

- 单行标题/菜单栏：40–44 DIP，应用小图标、文件/编辑/选择/查看/转到/帮助、搜索、Windows 窗口控制；不出现产品名称文字。
- 活动栏 44 DIP；文件树默认 232 DIP，可拖动和隐藏。
- 每编辑组独立标签，默认高 36–38 DIP；底部状态栏 24 DIP。
- 主界面一编辑组；参考分屏为左主区、右侧上下两区，不是固定最大组数。
- 设置作为标签；活动设置页左侧替换为设置分类。
- Markdown 所见即所得无源码行号；>_ 固定于当前正文右上，切换后以明显按下状态表示源码。

## 字体与密度

UI 为 Segoe UI、Microsoft YaHei、系统无衬线回退，默认 14 DIP；源码为 Cascadia Mono、Consolas、中文回退，默认 16 DIP / 24 DIP 行高。所见即所得正文使用 UI 中文字体与独立阅读排版，标题按 1.5 / 1.25 比例。默认不显示 minimap。控件 4 DIP 圆角，窗口边缘遵循系统支持，用细分隔线而非卡片与阴影分组。

## 状态

活动标签蓝色底线；未保存圆点；选区淡蓝；匹配琥珀色；当前行淡灰。警告、只读、外部变更与恢复均提供文字和具体动作。正文输入、光标移动和选区直接响应，尊重减少动效与高对比设置。

## 原型约束

prototype/src 为审阅原型源码，打包后 prototype/index.html 独立离线运行。外部审阅栏与“原型说明”明确能力边界，不属于最终产品窗口。原型不声称实现 NSH、TSF、原生多光标、真实文件监听或性能指标。
