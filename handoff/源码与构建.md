## 本机环境和命令

历史 Paladin 构建基线为 Windows x64、Rust 1.97.0、Visual Studio 2022 C++ Build Tools 17.14.45、MSVC 14.44.35207 和 Windows SDK 10.0.26100.0，详见 [环境基线](设计包/docs/ENV-BASELINE.md)。版本可能随本机环境变化，使用前确认。

在干净检出的项目根目录运行 PowerShell 7：

```powershell
git status --porcelain --untracked-files=all
pwsh -NoProfile -File scripts/build-candidate.ps1
```

脚本会验证工作树、范围文档与设计清单，再构建、测试并打包。请读取实际退出码、构建记录与候选内的身份信息。脚本对已有输出路径的要求以当前源码为准；需要新构建时使用新的干净工作树，保留已有产物。

最新候选的开发报告记录 222 项组件测试通过。复现特定 UI 场景时先核对测试机、EXE 的 SHA-256、当前前台与测试进程，再使用对应验证记录中的脚本和样本。

本机历史证据目录含多轮实验、失败、测试数据及构建工具。其内容未全部纳入交接提交，不应直接批量加入产品源码。原记录与无权限读取的测试恢复目录都已保留。
